# Homepage presentation contract

The homepage leads with continuation of useful work, not a generic promise to
organize information. Living Wiki remains the product category; it is not a
substitute for explaining what a visitor can do next.

## Narrative and retained assets

1. The entrance states the benefit: “You’ve done the work. Build on it.”
   Traditional Chinese: 「做過的功課，不必每次重來。」 Simplified Chinese uses
   natural local wording for the same benefit.
2. The adjacent scenario viewer starts with engineering, followed by client /
   project work and learning / research. Each scenario connects a prior note,
   a current question, and a next step supported by inspectable excerpts.
3. Acquisition links remain available. The system-recommended download precedes
   the real recorded demo; the dedicated download page retains platform detail.
4. The workflow illustration explains how notes become reusable pages. The
   original feature visuals remain: readable pages, graph context, sources,
   review, freshness, separated spaces, versioning, and tool continuity.
5. Hybrid Retrieval remains visible and explains keywords, semantic similarity,
   and graph relationships alongside the index / Markdown distinction.
6. Integrations distinguish sources from clients. Obsidian belongs beside source
   import and read-only collaboration, not in the list of MCP clients. Existing
   client icons and names are retained. The compact six-icon strip below the
   hero CTAs links to this detailed section, including Obsidian as a source tool.
7. Alternative workflows are described fairly. Wenlan's main comparison copy
   leads with its LLM-wiki v2 lifecycle: source documents and captured decisions
   jointly support maintained Pages; updates retain history and protect human
   writing through review. Configuration boundaries belong in setup/detail copy,
   not a defensive disclaimer appended to the main benefit.
   Benchmarks lead with the main-branch token bars (4,505 versus 168, on one
   zero-based scale). Quality metrics remain separate. The complete three-column
   table and scope stay in native expandable details, not a headline savings
   promise. FAQ and final download / email paths remain.
8. Real wiki/citation and selected graph frames from the launch recording have
   their own switchable, expandable showcase. Preserve real pixels even when
   the captured app theme differs from the website theme. Sources, extraction
   offsets and hashes are recorded in `docs/homepage-media-provenance.json`.

The evaluation date is explicitly a source snapshot date (2026-06-24), not a
new benchmark run. Card surfaces use 8px radii and media frames 12px; the hero
scenario card must follow the same panel scale. Motion establishes entry
hierarchy and interaction feedback, with visible SSR and reduced-motion fallbacks.

## Interaction and content boundaries

- Feature-card diagrams must fit their actual grid cell, including tablet widths.
  The six-tool visual converges vertically into the shared knowledge store; never
  hide overflow as a substitute for fitting its labels.
- No cursor-following aura/spotlight. Motion should trace connections and the
  retrieval sequence, with restrained displacement and reduced-motion support.
- Product screenshots never zoom/crop on hover. Choose a real frame with a visible
  page title and change the asset URL when changing the image to avoid stale
  optimized-image caches. The Wiki frame is now raw `03-cites-take3.mov` at 1.5s:
  full title, cursor on a citation, readable source-memory popover and entities.
  It replaces the clip 08 overview and is not claimed to occur in the published edit.

- Scenario selection is manual. Do not introduce an automatic carousel that
  changes an example while somebody is reading its sources.
- Tabs support keyboard navigation and have stable panel relationships. Inactive
  panels are inert; reduced-motion preferences disable transitions.
- Citation links open readable source excerpts. Only engineering links to the
  existing API worked example; unrelated scenarios must not link to that example
  as if it were their proof.
- Scenarios and feature diagrams are explicitly illustrative, not live product
  output, customer testimony, or measurements. The recorded demo remains the
  separate product demonstration.
- Claims preserve configuration and source-evidence limits. Source links do not
  certify every claim; unknown values remain unknown. Do not imply background
  synchronization of Obsidian or automatic universal freshness.
- Retain the existing brand typography, semantic dark/light tokens and restrained
  motion. CJK text must not inherit oversized quotation styling in example panels.
- Treat English, zh-TW and zh-CN as independent reading surfaces. Check narrow
  mobile and desktop renders, both themes, open sources and switched scenarios.

### Plain-language comparison revision, 2026-09-06

Compare storage, authorship and actual AI actions rather than declaring a tool
inherently more AI-native. Notion supports personal and team work; cloud storage
does not mean users lack ownership, export or offline access. Its Agent can
create and edit content, so do not describe AI as merely an add-on with no
agency. Obsidian keeps local Markdown notes and can be extended with AI tools.
For plain Markdown, explain finding relevant passages, telling current versions
from older ones, and checking what the answer cites. Avoid vague references to
an unspecified "workflow" or "review routine".

Official sources rechecked 2026-09-06:
- https://www.notion.com/help/notion-agent (search, create and edit pages)
- https://www.notion.com/help/back-up-your-data (cloud storage, ownership, exports)
- https://www.notion.com/help/use-pages-offline (downloaded pages, editing, sync)
- https://obsidian.md/ (private device storage, linking and extensibility)
- https://obsidian.md/help/data-storage (local Markdown files)
- https://community.obsidian.md/plugins/local-llm-helper (concrete optional AI extension)

The screenshot's greater visible connectivity improves the relevance of product
proof, not evidence of answer accuracy, retrieval quality, adoption or SEO gain.
